# كيف تساوي إضافة لحالك؟

خلّينا نبدأ بمثال صغير شغّال، ثم نفهم كيف انتقلنا منه لفكرة DeepSeek عربي. لا تحتاج React أو سيرفر أو حساب متجر حتى تتعلم وتجرب.

## 1. ما هي الإضافة؟

هي برنامج صغير يشغّله المتصفح. غالباً ستكتب ثلاثة أشياء تعرفها من صفحات الويب: HTML للواجهة، CSS للشكل، وJavaScript للسلوك. وفوقها `manifest.json`، وهو ملف يعرّف اسم الإضافة ونسختها وصلاحياتها ومتى وأين تشغّل ملفاتها. أمثلة Chrome الحالية تستخدم Manifest V3. [البداية الرسمية](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

## 2. أول مشروع: مفكرة محلية

المثال جاهز داخل `examples/my-first-extension`:

```text
my-first-extension/
├── manifest.json   ← تعريف الإضافة والصلاحية
├── popup.html      ← نافذة فيها مربع نص وزر
├── popup.css       ← تنسيق النافذة
└── popup.js        ← تحميل الملاحظة وحفظها
```

الفكرة محددة: تضغط أيقونة الإضافة، تكتب ملاحظة، وتحفظها على جهازك. هذه المفكرة مثال تعليمي مستقل عن إضافة DeepSeek، وليست ميزة ضمنها.

ابدأ بقراءة `manifest.json`:

```json
{
  "manifest_version": 3,
  "name": "أول إضافة إلي — مفكرة صغيرة",
  "version": "1.0.0",
  "description": "مثال تعليمي: مفكرة محلية صغيرة داخل نافذة الإضافة.",
  "permissions": ["storage"],
  "action": { "default_popup": "popup.html" }
}
```

`action.default_popup` يخبر المتصفح أي صفحة يفتحها عند الضغط على الأيقونة. `permissions` هنا تطلب التخزين فقط؛ المفكرة لا تحتاج الوصول لأي موقع. سمّ ملفاتك كما كتبتها في manifest تماماً، واستخدم JSON صحيحاً بدون تعليقات.

داخل HTML نربط الملفات، ونضع عناصر لها أسماء نستطيع الوصول إليها:

```html
<link rel="stylesheet" href="popup.css">
<script src="popup.js" defer></script>
<textarea id="note" dir="auto"></textarea>
<button id="save" type="button">حفظ</button>
```

ملف المثال الكامل يضيف أيضاً العنوان ورسائل الحالة. السكربت منفصل عن HTML، ونربط الأحداث بـ `addEventListener` بدلاً من `onclick` داخل الصفحة. `defer` يجعل الكود يعمل بعد تجهيز عناصر HTML.

السطران الأساسيان في الفكرة هما:

```js
const result = await chrome.storage.local.get("note");
await chrome.storage.local.set({ note: "ملاحظتي" });
```

`get` يقرأ، و`set` يحفظ. لأن العملية غير متزامنة نستخدم `await` داخل دالة `async`، أو `.then()` كما في ملف المثال. نافذة الإضافة تُغلق عند الخروج منها؛ لذلك لا تكفي قيمة متغير JavaScript لحفظ الملاحظة بين فتحات النافذة. [توثيق التخزين](https://developer.chrome.com/docs/extensions/reference/api/storage).

## 3. شغّل المثال الآن

1. افتح `chrome://extensions` أو `edge://extensions`.
2. فعّل Developer mode.
3. اضغط Load unpacked واختر `examples/my-first-extension`، لا المجلد الأب.
4. افتح المفكرة من أيقونة الإضافات، اكتب ملاحظة، واحفظها.
5. أغلق النافذة وافتحها مجدداً: المفروض تظهر ملاحظتك نفسها.

إذا احتجت إزالة الملاحظة، امسح النص واضغط حفظ. هي مخزنة محلياً في المتصفح، وليست مفكرة مشفرة أو خدمة نسخ احتياطي.

## 4. عدّل وتعلّم من النتيجة

نفّذ هذه التغييرات واحداً واحداً:

1. غيّر الاسم في manifest، واضغط Reload في صفحة الإضافات، وتأكد أن الاسم تغيّر.
2. غيّر لون الزر في CSS ثم أغلق نافذة الإضافة وافتحها. إذا لم يتحدث العرض أعد Reload.
3. غيّر رسالة «تم الحفظ» في JavaScript وتأكد أنها تظهر بعد الضغط.
4. أضف عدّاد أحرف يتحدث مع حدث `input`.
5. أضف زر مسح يستخدم `chrome.storage.local.remove("note")` ثم يفرغ المربع.

بعد كل خطوة جرّب السلوك بنفسك. إذا لم تعمل الإضافة، لا تغيّر عدة أشياء معاً؛ اقرأ رسالة الخطأ أولاً.

## 5. كيف تفحص الخطأ؟

- خطأ في manifest: يظهر عادة على بطاقة الإضافة في `chrome://extensions`.
- خطأ في نافذة المفكرة: افتحها، واضغط بالزر الأيمن داخلها ثم Inspect لقراءة Console وفحص HTML وCSS.
- خطأ في كود يعمل داخل موقع: افتح أدوات المطور للموقع واقرأ Console، واختر سياق الإضافة عند الحاجة.
- بعد تعديل content script أو manifest: أعد Reload للإضافة وحدّث تبويب الموقع؛ التبويب القديم قد يبقى عليه السكربت السابق.
- الصفحات الداخلية مثل `chrome://extensions` ليست صفحات ويب عادية يمكنك تعديلها بسكربت الإضافة.

خطأ شائع: طلب صلاحية في الكود ونسيان إضافتها إلى manifest. والعكس أيضاً شائع: إضافة صلاحيات لا يحتاجها المشروع. ابدأ بأقل صلاحية تحقق الوظيفة.

## 6. ما الفرق بين المفكرة وإضافة DeepSeek؟

| الجزء | دوره في DeepSeek عربي |
| --- | --- |
| `manifest.json` | يحدد أن الإضافة تعمل على `chat.deepseek.com` فقط ويفتح نافذة الإعدادات |
| `popup.html/css/js` | يعرض خيارات المستخدم ويكتبها إلى التخزين |
| `core.js` | يحتوي القيم الافتراضية والتحقق من الإعدادات وكشف اتجاه النص |
| `content.js` | يقرأ النص المعروض ومربع الكتابة محلياً ويضيف سمات العرض |
| `content.css` | يطبّق الاتجاه والخط مع حماية الأكواد والمعادلات |
| `chrome.storage.local` | يحفظ التفضيلات؛ وتصل تغييراتها إلى التبويبات عبر `onChanged` |

الـ content script كود يُحقن في المواقع المطابقة لحقل `matches`، ويستطيع التعامل مع DOM، أي عناصر الصفحة ونصوصها. لا يحتاج مشروعنا خادم خلفية أو service worker لأن content script يستطيع استعمال واجهة التخزين مباشرة. [شرح content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts).

في manifest المشروع الحقيقي ستجد:

```json
"content_scripts": [{
  "matches": ["https://chat.deepseek.com/*"],
  "js": ["core.js", "content.js"],
  "css": ["content.css"],
  "run_at": "document_idle"
}]
```

تُحمّل `core.js` أولاً، ثم `content.js` الذي يستخدم دواله. هذا أسلوب مشروعنا لتشارك الكود، وليس شرطاً عاماً لكل إضافة.

## 7. لماذا لم نكتب فقط direction: rtl لكل الصفحة؟

لأن نفس الرد قد يحتوي فقرة عربية، ثم فقرة إنجليزية، وكوداً، وجدولاً. تغيير اتجاه الصفحة كلها قد يغيّر الأزرار وترتيب العناصر. الحل في هذا المشروع هو:

1. اختيار عناصر محتوى الرسالة ومربع الكتابة.
2. تحديد اتجاه كل فقرة بناءً على نصها، مع استثناء الكود والمعادلات من حساب اللغة.
3. إضافة `data-*` خاصة بالإضافة، وتطبيق CSS عليها فقط.
4. متابعة ظهور نص جديد باستخدام `MutationObserver`، لأن الرد يصل تدريجياً.
5. عند التعطيل، إزالة السمات الخاصة بالإضافة لاسترجاع تنسيق الموقع.

كشف الاتجاه تقريب: إذا بدأت الفقرة بحرف عربي أو بلغت الحروف العربية ربع حروف الفقرة تقريباً، تختار دالة المشروع RTL. الروابط وعناوين البريد والكود المضمن لا تُحتسب مثل النثر. تستطيع قراءة هذه القاعدة وتغييرها في `core.js` وتجربة الاختبارات الموجودة في `tests/core.test.cjs`.

## 8. تمارين على المشروع الحقيقي

جرّبها على نسخة محلية قبل نشر أي تحديث:

- أضف خيار تباعد أسطر: قيمة افتراضية في `core.js`، عنصر تحكم في popup، حفظ عبر التخزين، ومتغير CSS يطبقه content script.
- أضف جملة تبدأ بـ API ثم نص عربي إلى اختبارات الاتجاه.
- جرّب التعطيل وتأكد أن النص الذي يرسله المستخدم لا يتغيّر.
- جرّب محادثة جديدة ثم الرجوع لمحادثة قديمة، لا الصفحة الأولى فقط.

إذا أردت لاحقاً إضافة تعمل عند ضغط المستخدم فقط على التبويب الحالي، تعلّم `activeTab` و`scripting`. وإذا احتجت معالجة أحداث خارج الصفحة أو مهام في الخلفية، تعلّم service workers. لا تحتاج إضافة هذه الأجزاء إلى كل مشروع. [activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab).

## 9. من الفكرة إلى النشر

اختر مشكلة واحدة، ابنِ أصغر نسخة تحلّها، جرّبها محلياً، ثم جرّبها على الموقع الحقيقي. بعدها جهّز الأيقونة والوصف والخصوصية والحزمة. [دليل النشر لهذا المشروع](PUBLISHING.ar.md) يشرح الخطوات. وللتحديث المنشور ارفع رقم النسخة وأعد الحزمة.

مسار تعلم مناسب: أساسيات HTML وCSS → JavaScript والأحداث وDOM → المفكرة → content scripts → التخزين والتواصل → الاختبار والنشر. لا تحتاج حفظ واجهات المتصفح كلها؛ اقرأ توثيق الواجهة عندما تحتاجها وجرّب مثالاً صغيراً عليها.
