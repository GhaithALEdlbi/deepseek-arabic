# Privacy policy / سياسة الخصوصية

Effective date / تاريخ السريان: 2026-11-14

## English

DeepSeek عربي — RTL & LTR is an independent browser extension maintained through the [GhaithALEdlbi/deepseek-arabic repository](https://github.com/GhaithALEdlbi/deepseek-arabic).

The extension runs only on `https://chat.deepseek.com/*`. It accesses visible message text and text entered into supported chat editors, processes that text in the browser to determine its writing direction, and applies presentation attributes and CSS. Message text and editor text are not saved by the extension or transmitted to the developer or any third party. It does not change the text sent to DeepSeek.

The only data the extension saves is four preferences in `chrome.storage.local`: whether it is enabled, the selected direction mode, the readable-font option, and the font size. These preferences stay in the local browser profile. The extension does not use sync storage, analytics, advertising, cookies, remote fonts, remote scripts, or its own network requests.

Preferences remain until the extension is removed or its local extension storage is cleared. Reset restores the defaults rather than deleting the stored record. The extension has no developer-operated server and no account system. It does not sell or share user data.

DeepSeek itself handles conversations according to its own policies. This policy covers only this extension. If you open a link using the popup or README, the destination site's policies apply. Information you voluntarily submit in a public GitHub issue is publicly visible under GitHub's policies; avoid posting private conversations.

Questions can be submitted through [GitHub Issues](https://github.com/GhaithALEdlbi/deepseek-arabic/issues). Changes to this policy will be published in this file with an updated effective date.

## العربية

إضافة DeepSeek عربي — RTL & LTR مشروع مستقل يُدار عبر [مستودع المشروع](https://github.com/GhaithALEdlbi/deepseek-arabic).

تعمل الإضافة فقط على `https://chat.deepseek.com/*`. تقرأ نصوص الرسائل الظاهرة والنص المدخل في مربعات المحادثة المدعومة، وتعالجها داخل المتصفح لتحديد اتجاه الكتابة وتطبيق سمات وتنسيقات عرض. لا تحفظ نصوص المحادثة أو الكتابة، ولا ترسلها للمطور أو لأي طرف ثالث، ولا تغيّر النص المرسل إلى DeepSeek.

تحفظ محلياً أربعة تفضيلات فقط باستخدام `chrome.storage.local`: التفعيل، وضع الاتجاه، خيار الخط، وحجم النص. لا تستخدم مزامنة الإعدادات، أو تحليلات، أو إعلانات، أو ملفات تعريف ارتباط، أو خطوطاً وسكربتات خارجية، أو طلبات شبكة خاصة بها.

تبقى التفضيلات حتى إزالة الإضافة أو مسح مخزنها المحلي. زر إعادة الضبط يعيد القيم الافتراضية ولا يحذف السجل المخزن. لا توجد خوادم يديرها المطور أو حسابات خاصة بالإضافة، ولا بيع أو مشاركة لبيانات المستخدم.

معالجة DeepSeek للمحادثات تخضع لسياساته؛ هذه السياسة تخص الإضافة فقط. عند فتح رابط من نافذة الإضافة أو دليلها، تنطبق سياسة الموقع المقصود. أي معلومات تنشرها طوعاً في Issue عام على GitHub تكون ظاهرة للعامة، لذلك تجنّب مشاركة محادثاتك الخاصة.

للاستفسارات استخدم [GitHub Issues](https://github.com/GhaithALEdlbi/deepseek-arabic/issues). تُنشر أي تعديلات على هذه السياسة في هذا الملف مع تحديث تاريخ السريان.
