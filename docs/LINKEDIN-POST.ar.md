إذا بتستخدم DeepSeek وبتكتب عربي مع English بنفس الرسالة، بتعرف قديش اتجاه النص ممكن يزعج القراءة، خصوصاً مع الروابط والأكواد.

جهّزت مشروع صغير اسمه «DeepSeek عربي» لمعالجة هالمشكلة: إضافة مفتوحة المصدر لـ Chrome وEdge، تركيزها تحسين عرض العربي والإنجليزي مع بعض.

شو فيها؟
• اتجاه تلقائي لكل فقرة، مع خيار RTL أو LTR يدوياً.
• ضبط اتجاه مربع الكتابة أثناء الإدخال.
• الحفاظ على اتجاه الأكواد والمعادلات وعزل الروابط ضمن النص.
• خط أوضح، حجم قابل للتعديل، وإعدادات محفوظة محلياً.

مبنية بـ JavaScript وCSS وManifest V3، بدون مكتبات تشغيل أو API key. معالجة النص بتصير داخل المتصفح؛ الإضافة ما بتحفظ المحادثات ولا بترسلها لأي جهة.

الفكرة مستوحاة من إضافات مثل RTL/LTR Magic، والتنفيذ هون مستقل ومتاح للتجربة والتطوير.

هذه نسخة تجريبية للتثبيت اليدوي، ولسّا ما نُشرت على متجر Chrome. اجتازت اختبارات محلية للاتجاه والتفاعل، وبهمّني أسمع ملاحظاتكم من الاستخدام الفعلي على DeepSeek.
